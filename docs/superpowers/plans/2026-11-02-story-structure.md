# 多篇故事結構實作計畫

目標：依使用者提供的規格，維持純靜態部署，以一個故事資料夾及一筆目錄資料新增故事。

架構：首頁讀取 stories/index.json；story.html?s=<slug> 載入 stories/<slug>/story.json。共用閱讀器與樣式置於 assets/，故事文字、注音、分頁、插畫與媒體路徑均由資料提供。

限制：不改既有文字與媒體；在 story-structure 工作，不推送或合併 main；所有文件與提交訊息使用繁體中文。

- [x] 使用 git mv 搬移媒體，抽出資料與共用閱讀器，新增目錄與舊錨點導向。
- [x] 新增資料範本及新增故事文件，更新 README。
- [x] 執行 npm test 與本機 HTTP 路徑驗證，檢查錯誤 slug、載入失敗、分齡切換、媒體路徑、閱讀進度隔離。
- [x] 審查差異並提交，推送 story-structure，建立以 main 為基底的 PR。

設計選擇：採用使用者建議的查詢參數路由；每篇複製 HTML 會造成閱讀器重複，故不採用。無錨點首頁展示目錄，既有故事錨點導向第一篇；第一篇原有閱讀進度沿用既有儲存鍵，其他故事獨立儲存。
